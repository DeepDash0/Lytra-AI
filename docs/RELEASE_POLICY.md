# Release Policy

Lytra's public repository and future model-weight releases are separate decisions.

Current direction:

- project documentation: public
- reproducibility/configuration material: public as cleaned
- training code: progressively published as cleaned
- raw training datasets: not promised for redistribution
- production weights: **planned open-weight release**
- final weights license: **TBD before release**

No pretrained Lytra V1 weights are published at this time.

A public GitHub repository does not by itself make future model weights open source or public-domain. The final model license will explicitly define permitted uses when weights are released.
